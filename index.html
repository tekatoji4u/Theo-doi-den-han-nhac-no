1. Dữ liệu hằng ngày

-- Chọn cán bộ --
Ghi nhớ thư mục: bấm nút đầu tiên, chọn thư mục BAO CAO CUOI NGAY FILE CSV trên ổ đã map (không chọn nguyên ổ đĩa, Desktop, Documents). Lần sau mở lại chỉ cần bấm Cập nhật dữ liệu; nếu trình duyệt hỏi quyền, chọn Cho phép (nên chọn “Cho phép mỗi lần truy cập” nếu có).
Dự phòng: nếu bị báo lỗi hoặc không ghi nhớ được, dùng nút thứ hai — không ghi nhớ nhưng ít lỗi; trình duyệt hỏi “Tải N tệp lên?” thì bấm Tải lên, công cụ chỉ đọc file trên máy bạn, không gửi đi đâu.
File nguồn: chưa nạp
File thông tin khách hàng: chưa nạp
Thư mục: chưa chọn
File dữ liệu: chưa lấy
Sẵn sàng.

2. Nguyên tắc theo dõi

Nguồn: file ZIP từ Intranet; bên trong là file Excel XLS/XLSX.
Lọc: cột K = Cán bộ được chọn.
Ngày đến hạn: cột O.
Chưa trả: cột U > 0.
Cần theo dõi: khoản quá hạn + khoản đến hạn trong 7 ngày tính từ ngày báo cáo.
Cập nhật dữ liệu: tải ZIP → giải nén → đọc Excel → lọc theo cán bộ → cập nhật và lưu dữ liệu theo dõi.

Ghi chú được lưu riêng trên trình duyệt này, không mất khi cập nhật dữ liệu mới.

3. Cài đặt cột Excel (theo chữ cái cột)

Mặc định đã khớp file dữ liệu hiện tại (K, O, U, B, C, D, S, T, M). Nếu file đổi cấu trúc, chỉnh chữ cái cột rồi bấm Lưu.

4. Thông tin thông báo nợ đến hạn (xuất file Word)

Số hợp đồng vay và ngày hợp đồng vay để trống trong file Word để bạn tự nhập. Nút xuất nằm ở tab Báo cáo.

5. Hướng dẫn sử dụng

  1. Lần đầu: bấm Chọn thư mục (ghi nhớ cho lần sau) và chọn thư mục BAO CAO CUOI NGAY FILE CSV trên ổ đã map. Công cụ tự tìm thư mục ngày yyyymmdd gần nhất, lấy file DENHAN_…ZIP và cập nhật dữ liệu.
  2. Các lần sau: mở công cụ rồi bấm Cập nhật dữ liệu (chọn “Cho phép” nếu trình duyệt hỏi). Muốn xem ngày khác thì chọn ở ô Ngày dữ liệu. Nếu không ghi nhớ được, dùng nút dự phòng. Cán bộ đã chọn được ghi nhớ.
  3. Chọn Ngày báo cáo, bấm Cập nhật dữ liệu, sau đó chọn Cán bộ.
  4. Tab Báo cáo: xem việc cần làm và ghi chú theo từng khoản (tự lưu). Tab Dashboard: xem biểu đồ thống kê.
  5. Bấm Xuất Excel theo dõi để lưu danh sách ra file.

Các tính năng chính

  1. Nhập dữ liệu: chọn thư mục, tải ZIP và Excel XLS/XLSX; hỗ trợ nguồn dữ liệu đối chiếu.
  2. Cập nhật dữ liệu hằng ngày: tìm thư mục ngày mới nhất, chọn ngày dữ liệu và cập nhật khi cần.
  3. Theo dõi theo cán bộ: lựa chọn một hoặc nhiều cán bộ phụ trách.
  4. Nhận diện đến hạn và quá hạn: theo dõi khoản quá hạn và đến hạn trong 7 ngày, có số tiền chưa trả.
  5. Lưu theo dõi: ghi chú và lưu kết quả theo dõi trên trình duyệt.
  6. Tra cứu và lọc báo cáo: tìm kiếm, lọc và xem danh sách khoản vay.
  7. Xuất báo cáo: Excel, bảng kê thu nợ, thông báo Word, HTML xem trên điện thoại và in/lưu PDF theo chức năng hiện có.
  8. Dashboard: tổng hợp, biểu đồ và so sánh số liệu.
  9. Cấu hình nghiệp vụ: thiết lập cột Excel và thông tin văn bản nhắc nợ.
  10. Giao diện: sidebar tự ẩn, tương thích thiết bị, chế độ sáng/tối/Auto và trang thông tin ứng dụng.

Khuyến nghị người dùng

  • Chỉ sử dụng dữ liệu nghiệp vụ theo đúng phân quyền và quy định bảo mật của đơn vị.
  • Kiểm tra ngày báo cáo, cán bộ phụ trách và số liệu nguồn trước khi sử dụng kết quả.
  • Đối chiếu dữ liệu quan trọng với hệ thống nghiệp vụ chính thức; không xem ứng dụng là nguồn dữ liệu pháp lý duy nhất.
  • Sao lưu dữ liệu và kết quả công việc theo quy trình được phê duyệt; không chia sẻ file chứa thông tin khách hàng qua kênh không được phép.
  • Khuyến nghị dùng Chrome hoặc Edge phiên bản mới; một số tính năng truy cập thư mục phụ thuộc quyền trình duyệt.
